## 🔧 TROUBLESHOOTING

### Problem: "Cannot find Python"
**Solution**: 
- Install Python from https://python.org
- Check "Add to PATH" during install
- Restart computer

### Problem: "Browser doesn't open"
**Solution**:
- Manually go to http://localhost:8000
- Check if port 8000 is free
- Try port 8080 instead

### Problem: "Canvas is blank"
**Solution**:
- Check browser console (F12)
- Refresh page (Ctrl+R)
- Clear cache (Ctrl+Shift+Delete)

### Problem: "Game loads but doesn't work"
**Solution**:
- Check F12 console for errors
- Make sure JavaScript is enabled
- Try different browser
- Check README.md

## 📱 MOBILE TESTING

### On Your Phone:
1. Find your computer IP: Type in terminal
   ```
   ipconfig
   ```
   (Look for IPv4 Address like 192.168.1.X)

2. On phone, open browser and go to:
   ```
   http://192.168.1.X:8000
   ```

3. Play the game!

### Install as App:
1. Open game on phone
2. Tap menu (⋮)
3. Select "Add to Home Screen"
4. Game appears as icon
