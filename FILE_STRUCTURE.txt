## How Each File Works Together

```
Browser Opens index.html
        ↓
Loads style.css (Styling)
        ↓
Loads scripts (Sequential)
├─ supportcheck.js (Checks browser support)
├─ poki-sdk.js (Sets up Poki SDK)
├─ offlineclient.js (Offline sync)
├─ main.js (DOM handling)
├─ c3runtime.js (Game engine)
└─ register-sw.js (Service worker)
        ↓
Loads appmanifest.json (PWA config)
        ↓
Loads icons (App branding)
        ↓
Loads analytics (Google Analytics)
        ↓
Game Starts! 🎮
```
